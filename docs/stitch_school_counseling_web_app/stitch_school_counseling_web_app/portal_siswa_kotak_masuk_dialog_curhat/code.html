spa Langkah Menenangkan Hari Ini (Grounding 4-7-8)

1. Ketika dada mulai terasa sesak, hentikan belajar selama 5 menit.
2. Tarik napas perlahan lewat hidung selama 4 detik.
3. Tahan napas selama 7 detik, lalu hembuskan lembut lewat mulut selama 8 detik.
4. Ulangi 3 kali sambil minum segelas air putih hangat.

Apakah siang ini kamu ada waktu luang setelah jam ke-6? Kita bisa duduk bersama di Sahabat Aman BK untuk membedah jadwal belajarmu menjadi bagian-bagian kecil yang lebih ringan, atau kita bisa tetap berbincang lewat pesan ini jika kamu merasa lebih nyaman.
